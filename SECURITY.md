# Политика безопасности

## Сообщение об уязвимости

Не публикуйте сведения о ещё не исправленной уязвимости в обычном issue.
Используйте приватный GitHub Security Advisory репозитория `prekel/typed-sql` и
приложите затронутую версию, минимальный пример, ожидаемое и фактическое
поведение и оценку влияния.

## Границы ответственности

Typed-sql проверяет identifiers, отделяет bind values от SQL template и не
вставляет пользовательские значения в SQL. Приложение отвечает за права
пользователя БД, TLS, secrets, transaction policy, timeout, ограничения
ресурсов и своевременное обновление драйверов.

Поддерживаемой считается последняя опубликованная версия. До первого релиза API
и security fixes находятся в ветке разработки.
